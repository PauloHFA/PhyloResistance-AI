## 🤝 Como Contribuir

Contribuições são muito bem-vindas! Se você deseja colaborar com novas linhagens bacterianas, integração de dados de vigilância (ex.: BR-GLASS, NCBI Pathogen Detection), melhorias nos modelos preditivos ou ferramentas de explicabilidade:

1. Faça um **Fork** do repositório.
2. Crie uma branch para sua funcionalidade ou correção:
   ```bash
   git checkout -b feature/minha-melhoria
   ```
3. Garanta que todos os testes passem e as regras de rigor científico sejam respeitadas:
   ```bash
   uv run ruff check src tests
   uv run pytest -v
   ```
4. Submeta um **Pull Request** detalhando as alterações.
